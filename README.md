# yas80

## ソース

- utf-8 エンコーディング

## 名前

- 大文字小文字の際は区別しない
- ユーザ定義名
    - `_` もしくは英字で始まり、以降 `_` 英数字が続く
    - ラベル
        - 通常ラベル
        - ローカルラベル
            - `.` で始まり、以降通常ラベルと同じ
            - 通常ラベルから次の通常ラベルまでのスコープを持つ 
            - 通常ラベルの直後にローカルラベルを続けることで、他のスコープから参照できる
    - 定数
        - `CONST` もしくは `EQU` で定義
        - 例）v1 を 1 として定義
            - `CONST v1 = 1`
            - `v1 EQU 1`
        - 再定義は不可（値が同じ内容、表現でも不可）
    - 変数
        - `VAR` で定義
            - `VAR v1 = 1`
        - 代入が可能
        - 再定義は不可
- 予約語
    - Z80 命令
    - Z80 フラグ
    - z80 レジスタ
    - ディレクティブ
    - `$COUNT`  REPEAT マクロの評価時のカウンタ(0 開始)
    - `$`  カレントアドレス

## リテラル

- 数値
    - 10 進数
    - 16 進数
        - `0x` / `0X` で始まる
        - `$` で始まる
        - 末尾が `h` `H`
    - 8 進数
        - `0o` で始まる
    - 2 進数
        - `0b` で始まる
        - `%` でではじまる
    - いずれの場合も `_` を含んでいてもよい

- 文字列
    - `"` で囲まれたもの
    - `"` そのものはエスケープシーケンスで定義
    - 有効なエスケープシーケンス
        - `\"`
        - `\xhh'` hh' は2桁の16進数
- 論理
    - 論理リテラルはない
    - 0 以外の数値、文字列は 真
    - 数値 0 ""（空文字）は偽
