# yas80 - Yet Another Assembler for Z80 and R800 概要


## 主な特長

- マルチパスアセンブラ
- グローバル/PROC/マクロ スコープ
- ORG による生成コードの配置指定
- マルチステートメント
- 行継続
- 連続する文字列リテラルの結合
- 変数（再代入可能シンボル）
- シンボル結合演算子（##）
- 複数行関数
- 関数クロージャ
- EXITM マクロ制御構文
- JSON 文字列を指定した CHARAMP 生成
- CHARMAP 未定義文字の扱い（エラー、特定文字、元の文字）
- SETMAP による CHARMAP 更新
- 配列リテラル
- R800 命令

### 計測方法

- Python スクリプトで対象ソースファイルを所定の 100 回アセンブルし、各回の実行時間（単位: 秒）を計測
- 実行結果から実行時間の合計（総実行時間）、および 1回あたりの平均実行時間を求める
