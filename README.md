# yas80 - Yet Another Assembler for Z80 and R800

<div style="color:red;font-size:2em;font-weight:bold">UNDER CONSTRUCTION </div> 

## 特長

- マルチステートメント
- 継続行
- PROC によるシンボルスコープ管理
- シンボル結合演算子（##）
- 変数 - アセンブル中再代入可能なシンボル
- ORG addr, ABS/REL によるアドレス指定と出力ファイル内で配置指定
- EXITM による柔軟なマクロロジックの組み立て
- ロード後に変更可能な CHARMAP
- 配列リテラルによる $ISARRAY 組み込み関数による可変長マクロ引数
- REPT + 配列リテラルによる配列要素を引数とした展開
